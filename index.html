Get to know me!

Hello! I'm Reginaldo Junior, a Software Quality Assurance (QA) Engineer with end-to-end testing lifecycle experience, combining a solid foundation in manual, functional, and exploratory testing with technical capabilities in test automation (E2E & APIs). I hold a postgraduate specialization in Software Quality and Testing Engineering (PUC Minas) and an academic degree in Systems Analysis and Development.

I have a proven track record across high-scale, mission-critical environments—including digital banking (C6 Bank via act digital) and logistics (Frenet)—ensuring production stability through regression suites, integration testing, user acceptance testing (UAT), and direct database verification with SQL.

Skilled in requirements analysis, test planning, BDD (Gherkin / Cucumber), and detailed defect management (Root Cause Analysis & observability with Datadog), I supplement manual QA strategies with automated regression flows using Playwright, Cypress, Robot Framework, and CI/CD pipelines. QA AI Playground - Interactive DevTools & QA Engineering Suite

An interactive DevTools & Quality Engineering (QA) environment built with React, TypeScript (Strict Mode), Tailwind CSS, Monaco Editor, and the Google Gemini SDK. Designed to accelerate the testing lifecycle through three specialized modules: Smart Data Mock (strict RFC 8259 JSON test fixture generation with edge cases, boundary values, null/empty fields, and XSS/SQLi payloads), BDD Test Generator (converts Gherkin specifications into executable Playwright, Cypress, and Robot Framework scripts using Page Object Model), and API Contract Check (automated schema validation scripts for Playwright + Zod, Cypress + AJV, and Postman + Chai). Engineered with a resilient Circuit Breaker, 15s strict timeout, and local fallback contingency.

Technologies: React · TypeScript · Playwright · Cypress · Robot Framework · Google Gemini SDK · Monaco Editor · Tailwind CSS · Zod / AJV
